# Research source snapshots

This directory contains source-only snapshots of the two MMaDA decoding
experiments:

- `cd-apc/`: CD-APC / DCD experiment source, integration code, and tests.
- `history-vchd/`: History-VCHD source, integration code, tests, and run
  scripts.

Model checkpoints, datasets, generated evaluation outputs, caches, and
compiled Python files are intentionally excluded.
